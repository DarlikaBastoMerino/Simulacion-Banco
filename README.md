# Simulacion-Banco
Este proyecto consiste en una simulación de la atención de clientes en un banco utilizando Python y la librería SimPy.

El programa permite ingresar datos como la cantidad de clientes, número de cajeros y los tiempos de llegada y atención. Los tiempos se generan de forma aleatoria dentro de los valores establecidos.

Al terminar la simulación, se muestran algunos resultados como el tiempo promedio de espera, el tiempo máximo, la cantidad máxima de personas en fila y el tiempo total de la simulación.

El objetivo es observar cómo se comporta el sistema de atención y analizar los tiempos de espera de los clientes.
